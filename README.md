# โอวาทปาติโมกข์ (Ovāda Pātimokkha)
> **Sustainable Development & Social Engagement through Dhamma**

โปรเจกต์นี้รวบรวม "โอวาทปาติโมกข์" ทั้ง ๓ คาถา ซึ่งเป็นหัวใจสำคัญของพระพุทธศาสนา โดยเรียบเรียงให้ครบถ้วนทั้ง **พยัญชนะ (บาลี)** และ **อรรถะ (คำแปล)** เพื่อเป็นรากฐานในการพัฒนาจิตใจและสังคมอย่างยั่งยืน

### โครงสร้างเนื้อหา (Content Structure)
- **Pali (Thai & Romanized):** รักษาต้นฉบับเสียงเพื่อความแม่นยำ
- **Thai Translation:** เพื่อความเข้าใจในบริบทท้องถิ่น
- **English Translation:** เพื่อการเข้าถึงระดับสากล (Universal Accessibility)

### อุดมการณ์และความยั่งยืน
เนื้อหาในโปรเจกต์นี้สนับสนุนแนวคิด:
1. **Individual Sustainability:** การฝึกจิตและสำรวมกายวาจา
2. **Social Engagement:** การไม่ว่าร้าย ไม่ทำร้าย และการอยู่ร่วมกันโดยสันติ
3. **Minimalist Approach:** นำเสนอธรรมะด้วยรูปแบบที่เรียบง่าย แต่ทรงพลัง (Less is More)
